# 译芯怡意 · 猫档案系统 体验说明

> 写给：明早 9 点来体验的老板（不需要任何技术基础，照着做就行）
> 版本：M1（猫档案 + 情绪时间线/统计/周报/导出）· 2026-09-07

---

## 一、开始之前（30 秒）

- 你只需要：一台 Windows 电脑（就是这台，项目已装好）、一个浏览器（Edge 或 Chrome）
- 整个体验在你的电脑上本地运行，**不会碰线上正式数据**：数据库和录音都使用 `demo` 文件夹里的副本
- 测试素材不用自己找：`译芯怡意\demo\recordings` 里有现成的猫叫录音（.wav 文件），拖进去就能用

## 二、启动（复制下面整块命令即可）

1. 点屏幕左下角「开始」，输入 **PowerShell**，点开「Windows PowerShell」
2. 把下面**整块**命令一次性复制、粘贴进蓝底窗口，然后按回车：

```powershell
# ① 进入项目目录
cd PROJECT_ROOT\app

# ② 安装运行依赖（装过会自动跳过，很快）
pip install -r deploy_requirements.txt

# ③ 准备演示数据副本（在译芯怡意文件夹下建 demo 文件夹，正式数据不碰）
mkdir ..\demo -Force
Copy-Item data\app.db ..\demo\app_demo.db
Copy-Item data\recordings ..\demo\recordings -Recurse -Force

# ④ 让程序使用副本数据
$env:YXY_DB_PATH = "PROJECT_ROOT\demo\app_demo.db"
$env:YXY_RECORDINGS_DIR = "PROJECT_ROOT\demo\recordings"

# ⑤ 启动（等几秒，看到两只 ✅ 已加载 ONNX 就是成功了）
python cloud_server.py
```

3. 窗口里出现 `✅ 已加载 ONNX` 之后，**保持这个蓝窗口开着别关**（关了服务就停了）
4. 打开浏览器，访问：**http://127.0.0.1:5173**

> 小提示：
> - 如果 Windows 弹出「防火墙」询问框，点「取消」也没关系，本机访问不受影响
> - demo 文件夹里出现 `app_demo.db.bak_…` 备份文件属正常现象，是程序自动留的快照
> - 想重新演示一遍：在蓝窗口按 `Ctrl+C` 停止，把整块命令再粘贴执行一次即可

## 三、体验动线（按顺序走，约 10 分钟）

**第 0 步：隐私提示（只出现一次）**
第一次打开主页会弹出「开始使用前，想说清楚数据这件事」提示框，说明收集什么、怎么用。
✅ 预期：点「我已知晓」后收起，之后不再自动弹出（浏览器会记住）。页面**左下角**有「🔒 隐私说明」固定入口，随时可点开重看；完整版文字见 `docs/隐私说明.md`。

**第 1 步：上传识别一只猫的叫声**
主页中间的上传区，把 `译芯怡意\demo\recordings` 里任意一个 `.wav` 文件拖进去（或点上传选择）。
✅ 预期：几秒后出现识别结果——猫咪情绪（如"战斗"）、一句"猫话"翻译、养护建议。
（如果**录音太短**（不足约 1.5 秒），页面会直接提示「录音太短啦——请贴近猫咪录满 2 秒以上再松手」，本次不会发起识别——拉长录音再试即可。）

**第 2 步：进入猫档案**
看页面**右下角**，有一个「🐱 猫档案」圆形按钮，点它。
✅ 预期：跳转到猫档案页。

**第 3 步：建一只猫**
点「＋ 新建猫档案」→ 起个名字（如"咪咪"）、挑个头像颜色和表情 → 点「保存」。
✅ 预期：顶部出现这只猫的名牌，并自动选中它。之后每次识别都会自动记到它名下。

**第 4 步：认领刚才的识别记录**
回到时间线，顶部有一条黄色提示框：「有 N 条未归属的识别记录」→ 点「归到「咪咪」」。
✅ 预期：这条记录进入咪咪的时间线。（时间线里每条记录也能用「换归属」改给别的猫。）

**第 5 步：时间线 / 统计 / 周报**
- 📜 **时间线**：按天排列的情绪日记，每条带时间、置信度、翻译
- 📊 **统计**：近 7/30 天识别次数、异常情绪次数、最常见情绪、趋势图
- 🗓 **周报**：点「打开周报（可打印）」→ 新窗口里点右下角「打印 / 存 PDF」可存纸质版或 PDF

**第 6 步：导出数据**
- 📤 **导出 CSV**：Excel 双击就能打开的表格
- 📤 **导出 JSON**：同内容的备份格式
- ☁️ **全量备份**：一个文件带走所有猫+全部记录。**会弹框要口令，输入：`demo-key`**（输入一次就记住了）

**第 7 步：数据监控页**
浏览器地址栏直接输入：`http://127.0.0.1:5173/stats?key=demo-key`
✅ 预期：打开数据统计页（识别请求、用户数、回访率等卡片）。不带口令访问会被拒绝（403），这是故意的。

**第 8 步（可选）：再识别几次**
回主页多传几段录音，档案页的时间线和统计会实时长出来，演示效果更好。

## 四、已知限制（如实说明）

1. **界面级自动化已就绪，可一键重跑**：`python scripts\ui_regression.py` 会在真实浏览器（系统 Edge，无需下载）里把本说明的主要动线自动点一遍（14 步，含隐私弹窗/短录音提示），全过退出码 0；接口层另有 `python scripts\smoke_e2e.py`（15 步）。如人工走查某步卡住，先跑这两个脚本定位是页面问题还是环境问题
2. **生产部署前，备份/统计接口的口令需要改为环境变量注入**（目前 `demo-key` 写在 cloud_server.py 里，仅用于本地演示）
3. **演示期间的访问/埋点日志**会写入 `app\data\` 下的 `calls.jsonl`、`events.jsonl`、`feedback.jsonl`（都是新文件，不影响正式数据；数据库和录音已走 demo 副本）
4. **演示从空档案开始**（本地库还没有猫数据），正好按上面动线现场建：先传 1~2 段猫叫 → 建猫 → 认领
5. 识别仅支持**猫叫**：人声或安静片段会提示"没有听到猫叫声"，换一段即可；过短录音（<1.5 秒）页面会直接提示"录音太短啦"
